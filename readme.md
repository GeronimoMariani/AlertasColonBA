# 🚨 Sistema de Alertas - Bomberos Voluntarios de Colón BA

Este es el sistema oficial de gestión y despacho de alertas diseñado exclusivamente para el **Cuartel de Bomberos Voluntarios de Colón, Buenos Aires**.

---

## 👨‍🚒 Autoría y Desarrollo
Este proyecto ha sido desarrollado íntegramente por:
**Bombero Mariani Gerónimo**

Como integrante del cuerpo activo, este sistema nace de la necesidad de optimizar los tiempos de respuesta y la comunicación interna ante emergencias en nuestra ciudad.

---

## 🛠️ Funcionalidades Principales
El sistema permite centralizar la comunicación de incidentes a través de múltiples canales:

| Módulo | Descripción |
| :--- | :--- |
| **Panel de Despacho** | Interfaz en tiempo real para el envío de alertas críticas. |
| **Notificaciones Telegram** | Integración automática con bots para aviso inmediato a los grupos operativos. |
| **Gestión de Usuarios** | Sistema de roles y aprobación de despachadores autorizados. |
| **Historial de Alertas** | Registro persistente en Firebase para auditoría y estadísticas de servicios. |
| **Multiplataforma** | Acceso vía web optimizado para dispositivos móviles y centros de monitoreo. |

---

## 🚀 Tecnologías Utilizadas
Para garantizar la estabilidad y rapidez del sistema, se han empleado las siguientes tecnologías:

*   **Backend:** Node.js con Express.
*   **Tiempo Real:** Socket.io para comunicación instantánea.
*   **Base de Datos:** Firebase Firestore para almacenamiento seguro.
*   **Notificaciones:** API de Telegram y SendGrid (Email).
*   **Seguridad:** Encriptación de contraseñas con Bcrypt y Rate Limiting.
*   **Despliegue:** Render para hosting escalable.

---

## 🛡️ Seguridad y Privacidad
Este sistema es de **uso restringido**. El acceso está limitado a personal autorizado del Cuartel de Bomberos de Colón BA. Todas las credenciales y datos sensibles se manejan mediante variables de entorno para garantizar la máxima seguridad del servicio.
